# AGENTS.md

Hive Gateway 2.15.4 serving the Rover-composed supergraph for the home cluster.
The aggregation path only: the gateway is ClusterIP-only, has no edge route, and
is declared in `home-cluster` (`developer/apps/baremetal/home-graphql.yaml`). Vocabulary and
the full decision live in the wiki repo (`service-networking` ADR).

## Commands

Everything runs through Docker (nothing installed on the host).

| Task | Command |
|---|---|
| Compose the supergraph + sync chart files | `./scripts/compose.sh` |
| Lint the chart | `docker run --rm -v "$PWD:/src" -w /src alpine/helm:latest lint deploy/home-graphql` |
| Check root/chart copies | `./scripts/check-config-sync.sh` |
| Render the chart | `docker run --rm -v "$PWD:/src" -w /src alpine/helm:latest template home-graphql deploy/home-graphql -n home-graphql` |
| Syntax-check the gateway config | `docker run --rm -v "$PWD:/src:ro" -w /src node:22-alpine node --check gateway.config.mjs` |
| Mint a test JWT | `node scripts/mint-test-jwt.mjs` (or the node container) |
| Deploy | `helm upgrade --install home-graphql deploy/home-graphql -n home-graphql --create-namespace` |

## Rules

- **Hive config must stay `.mjs`/`.js`.** Hive Gateway has no YAML config;
  `supergraph.yaml` is Rover's file, not the gateway's.
- **The supergraph source is a function plus `pollingInterval: 10_000`.**
  A plain path string makes the CLI use `fs.watch` and delete the interval;
  a ConfigMap update is an atomic symlink swap (a `rename`), which kills that
  watcher. Never lower the interval below 10 s (the CLI exits) and never mount
  the ConfigMap with `subPath`.
- **`gateway.config.mjs` and `supergraph.graphql` at the root are canonical.**
  The chart's `files/` copies are generated by `scripts/compose.sh`, and
  `scripts/check-config-sync.sh` must pass (it runs in the offline checks in
  `tests/README.md`). Helm `.Files` cannot read outside the chart, so do not
  hand-edit the copies.
- **Rover is pinned**: image 1.0.1, `federation_version: =2.9.3`, plugin
  `supergraph@=2.9.3`. Bump both together and commit the recomposed artifact.
- **`schemas/users.graphql` is fetched verbatim** from
  `{ _service { sdl } }`; do not hand-write it.
- **One replica, no PDB** is deliberate (ADR). Do not add a PDB without a
  second replica.
- **No edge route**: the Service is ClusterIP; callers use Service DNS. If a
  UI needs the gateway, add it as a caller in the Cilium policy and via the
  edge only after an explicit decision.
- **Namespace stays ambient + restricted + STRICT mTLS.** Never relax it to
  make a caller work.
- **Schema changes go through the shared Tekton pipeline.** Manual trigger, no
  breaking-change gate: `developer/pipelines/charts/supergraph-release/`
  (`supergraph-release-v1`). It composes with the same pinned Rover plugin and
  applies `home-graphql-supergraph` in place; the gateway polls it. A failed
  composition never reaches the ConfigMap.
- **A manual release is not a Git commit.** Refresh `schemas/*.graphql`,
  run `scripts/compose.sh` and commit the artifacts after a live release, or
  the next `helm upgrade` rolls the ConfigMap back to the committed supergraph.
- **All YAML parses** (`helm lint`/`helm template`) before declaring work done.

## Layout

- `supergraph.yaml`, `schemas/`, `supergraph.graphql`, `gateway.config.mjs` —
  composition inputs and artifacts.
- `deploy/home-graphql/` — chart (namespace, deployment, service, two
  ConfigMaps, `PeerAuthentication` STRICT, CiliumNetworkPolicy, probes).
- `scripts/` — compose and test-token helpers.
- `tests/fixtures/` — public throwaway RSA key for test tokens only.

## Security

- No real secrets, LAN addresses, or kubeconfigs. The test key is a public test
  fixture; production JWT settings point at Cognito (ticket #17).
- The gateway forwards only the raw `Authorization` header; services validate
  it again. Do not introduce trusted identity headers.
- Production defaults are Cognito **placeholders**: no pool id is committed,
  the audience is empty (access tokens have no `aud`) and `jwtClientId` is
  `<client-id>`. The gateway throws at startup while `JWT_ISSUER` is unset or
  still contains `<...>`, so a forgotten placeholder fails loudly.
  `values-verification.yaml` switches to the test issuer/JWKS and
  `client_id: home-test-client`; keep it test-only.
- The DNS egress rule needs its Cilium L7 `rules.dns.matchPattern: "*"`; the
  Cognito `toFQDNs` entry is derived from `config.jwksUri` and omitted while
  the URL is a placeholder or the in-cluster HTTP JWKS.
- `@requiresScopes` is owned by the subgraph SDL and composed into
  `supergraph.graphql`. Do not hand-add scope directives to the composed
  artifact. `genericAuth` (`protect-granular`) enforces them; the JWT plugin's
  `reject` stays on so unauthenticated requests never reach query planning.
